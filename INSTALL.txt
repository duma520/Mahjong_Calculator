国标麻将算番器 v2.9.48  ·  三步安装与快速上手
Mahjong_Calculator  ·  https://github.com/duma520/Mahjong_Calculator
================================================================================

【这是什么】
  一个纯本地的国标麻将算番工具。点牌 → 立刻给出：共几番、由哪些番种组成、
  够不够 8 分起和、还听哪几张牌、每张听牌各多少番。
  另外送一块能投到电视 / 投影上的实时战绩大屏看板（桌面窗口 + 网页版）。

  不联网、不赌博、不上传任何数据。


================================================================================
一、三步装好（Windows）
================================================================================

第 1 步：下载
  打开 https://github.com/duma520/Mahjong_Calculator/releases/latest
  下载其中一个：
    · Mahjong_Calculator-v2.9.48-win64-portable.7z    ← 推荐，解压即用，不写注册表
    · 或自己用源码跑（见下面「四、从源码运行」）

第 2 步：解压
  ★ 重要：装到一个**你自己有写权限、路径里没有中文和空格**的目录，例如
        D:\Mahjong_Calculator
    不要放在 C:\Program Files\ 下面（那里需要管理员权限，程序要读写
    同目录下的设置文件和统计数据库，会失败）。
    不要直接在压缩包里双击 exe 运行（压缩包里的文件是只读的临时副本，
    设置存不下来）。

第 3 步：双击 Mahjong_Calculator.exe
  第一次启动会自动在同目录生成两个文件：
    · mahjong_settings.json    所有设置（实时自动保存，下次启动自动加载）
    · mahjong_stats.db         算番统计数据库（Web 版 / 看板的数据来源）
  这两个文件删掉＝恢复出厂设置，程序会重新生成。

  如果 Windows 弹出「已保护你的电脑」（SmartScreen）：
    点「更多信息」→「仍要运行」。
    原因：exe 没有买代码签名证书（个人开源项目通常都不买，
    一张证书一年几千元）。程序是开源的，源码就在仓库里，可以自己编译。


================================================================================
二、最快上手：30 秒算一手牌
================================================================================

  假设你想算这一手（14 张）：
      1万 2万 3万 | 4万 5万 6万 | 7万 8万 9万 | 1筒 1筒 1筒 | 东 东

  1) 在「牌选择区」点牌
       点 1万 2万 3万 4万 5万 6万 7万 8万 9万（各一下）
       点 1筒 三下
       点 东 两下
     → 一共 13 张（第 14 张是「和张」，最后单独点）

  2) 看「听牌候选」
     软件自动列出你能和的牌和番数。

  3) 点一张听牌当「和张」
     比如点 东 → 结果区立刻显示「共 xx 番」+ 番种明细。

  4) 想重来：点「重置」。

  ★ 三个最容易踩的坑：
    · 点和张之前先把立牌点满 13 张，否则算不出来。
    · 同一张牌最多 4 张，第 5 下会提示「这种牌最多 4 张」。
    · 「起和」不勾也行 —— 软件会告诉你这手够不够 8 分，不是拦住你。

三、想把战绩投到电视上（可选）
================================================================================

  方式 A：桌面大屏看板（一根 HDMI 线最省事）
    统计页 → 「📺 大屏看板」→ 新窗口开出来 → 「⛶ 全屏」或 F11
    设置：窗口底部「⚙ 上墙设置」四页（数据 / 外观 / 配色 / 窗口）

  方式 B：网页版看板（电视盒子、手机、平板都能看，不用投屏）
    1. 设置 → Web 版 → 勾「启动 Web 服务」+「允许局域网访问」
    2. 统计页 → 「🌐 Web 看板地址」（自动复制到剪贴板）
    3. 电视盒子 / 手机浏览器打开那个地址（形如 http://192.168.1.100:8080/wall）

  两者数据、配色、分档规则完全一样（同一个数据库、同一套算色逻辑）。
  网页版每 2 秒自动刷新，电脑上改了配色网页立刻跟着变，不用重启服务。

四、从源码运行（开发者 / 想自己改）
================================================================================

  环境：Windows 10/11 + Python 3.10+ + PySide6

    python -m pip install PySide6
    python Mahjong_Calculator.py

  命令行算番（不需要图形界面）：

    python Mahjong_Calculator.py --score "1112345678999m+9m"
    python Mahjong_Calculator.py --version

  自己编译 exe（Nuitka，约 15~40 分钟）：

    python _scaffold/build_exe.py

  跑全部自动化验证：

    python _scaffold/smoke_test.py          # 主界面 343 项
    python _scaffold/api_smoke_test.py      # HTTP 接口 273 项
    python _scaffold/_wall_ui_smoke.py      # 大屏看板 85 项

五、遇到问题先看这里
================================================================================

  · 双击没反应 / 一闪就退
      用命令行启动看报错：在 exe 所在目录打开 cmd，输入 Mahjong_Calculator.exe
      最常见原因：解压在压缩包里没真正解出来，或者目录没有写权限。

  · 打不开 / 中文变方块
      缺字体。程序优先用 HarmonyOS Sans SC / Noto Sans SC（免费可商用），
      都没有就退回系统默认字体。

  · 网页版手机打不开
      ① 设置里「允许局域网访问」有没有勾
      ② Windows 防火墙第一次会弹窗问「是否允许」，要选「允许」
      ③ 手机和电脑是不是同一个 Wi-Fi / 同一个网段
      ④ 电脑的 IP 变了 —— 重新点「🌐 Web 看板地址」拿新地址

  · 统计页空的
      统计要「Web 端或桌面端真的算过一手」才会入库。空库是正常的。

  · 看板颜色分不出来
      ⚙ 上墙设置 → 🌈 配色 → 换「彩虹」（4 人各占一色，色差最大）
      或 🌈 配色 → 分档方式 → 「按名次铺开」（默认就是它）

  详细的排错手册（按症状查，含日志位置、报错原文）：
      仓库里的 README.md 第十部分「常见问题（按人群分类）」
  踩过的坑汇总（开发与使用两边都适用）：
      仓库里的 避坑指南.md
