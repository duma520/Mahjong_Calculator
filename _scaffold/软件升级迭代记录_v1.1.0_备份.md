## 二、主程序运行逻辑（分析结果，改动前必读）

### 2.1 类与职责

| 类 | 职责 | 关键成员 |
| --- | --- | --- |
| `TileButton(QPushButton)` | 单张牌的图标按钮，点击循环 0→1→2→3→4→0 计数 | `tile_type`、`count`、`max_count`、`image_path`、`on_click()`、`update_display()` |
| `MahjongFanCalculatorUI(QMainWindow)` | 全部界面与交互 | 见下 |

### 2.2 界面结构（自上而下）

1. **菜单栏**：`帮助(H)` → `关于(A)`、`规则数据来源(R)`（v1.1.0 新增）
2. **牌选择区**（`QScrollArea`）：4 行 —— 条子 T1~T9、饼子 B1~B9、万子 W1~W9、字牌 F1~F4 + J1~J3，共 34 个 `TileButton`
3. **操作按钮行**：`立牌`、`吃`、`碰`、`明杠`、`暗杠`、`重置`（目前只有「重置」有实现）
4. **特殊番种复选框**：`自摸`、`和绝张`、`抢杠和`、`海底捞月`、`天和`、`地和`
5. **圈风行**：东/南/西/北（互斥单选，用 QCheckBox 模拟）
6. **门风行**：东/南/西/北（互斥单选）
7. **花牌行**：春/夏/秋/冬/梅/兰/竹/菊，每个 `QSpinBox(0~1)`
8. **`selected_tiles_label`**：已选牌统计显示
9. **`hint_label`**：提示（请选择 14 张牌 / 和牌 / 诈胡）
10. **`ting_result_label`**：番种与总番数、听牌分析结果

### 2.3 数据流与状态

```
TileButton 点击
   └→ on_tile_selected(tile_type)        # 追加到 self.selected_tiles（上限 14）
        ├→ hint_label 更新剩余张数
        ├→ update_selected_tiles_display()  # defaultdict 统计后显示
        ├→ 满 14 张 → check_winning_hand() → update_calculation()
        └→ 恰 13 张 → analyze_ting()

复选框 / 圈风 / 门风 / 花牌 spin 变更
   └→ update_calculation()   （同时由 v1.1.0 起：特殊番种与花牌还会触发 _autosave_settings）

update_calculation()
   └→ 组装 config = {round_wind, seat_wind, flowers, special_fans}
        └→ calculator.calculate_fan(self.selected_tiles, config)  → display_fan_result()
```

- `self.selected_tiles` 是**唯一的牌型状态**（字符串列表，如 `["W1","W2","W3",...]`），不持久化（属临时状态）。
- **设置类状态**：圈风、门风、6 个特殊番种复选框、8 个花牌计数、窗口几何、窗口最大化 —— v1.1.0 起全部实时自动保存。
- 牌张代码约定与 `tiles\` 文件名一致：`W`万、`B`饼、`T`条、`F`风(东南西北=1~4)、`J`箭(中发白=1~3)。

### 2.4 与外部模块的接口（`mahjong_core.MahjongFanCalculator`）

```python
calc = MahjongFanCalculator()                                  # 读规则文件 + 建反向索引
calc.calculate_fan(tiles: List[str], config: Dict) -> Dict[str, int]
calc.is_winning_hand(tiles: List[str]) -> bool
calc.get_possible_winning_tiles(tiles: List[str]) -> List[Tuple[str, Dict[str, int]]]
```

`config` 的键：`round_wind`（圈风，中文）、`seat_wind`（门风，中文）、`flowers`（花牌张数，int）、
`special_fans`（特殊番种中文名列表）。

**关键结论（易踩坑，勿重复考证）**

1. 国标番种共 **81 个**，12 个分值级（88/64/48/32/24/16/12/8/6/4/2/1），9 大系列；各分值个数
   = 7/6/2/3/9/6/5/9/7/4/10/12 + **花牌**1 = 81。
2. **国标没有「天和、地和、人和」**（《问答》Q12：机遇性太大，不予采用）。
3. **花牌（春/夏/秋/冬/梅/兰/竹/菊）每张 1 分，但不计入 8 分起和分**。
4. 计分公式：自摸 `(底分8 + 基本分) × 3`；点和 `底分8 × 3 + 基本分 × 1`。
5. 计分五原则：不重复、不拆移、不得相同、就高不就低、套算一次。
6. 番种的「不计」列表是《规则》原文的**必然并存排除项**，是算番实现里最容易错的部分。
7. 旧版 `国标麻将标准规则.json` 中「清幺九 exclude = 碰碰和/混幺九/幺九刻」与《规则》分值表原文
   「不计碰碰和、同刻、无字」不一致，本版按原书并加 `ocr_uncertain_note` 说明。
8. OCR 常见误字：麻将→厅将/肥将、和牌→有牌、碰→磁/倍、杠→枉/柱、掷骰→掷山/掷敏。
